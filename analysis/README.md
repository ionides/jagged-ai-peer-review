A brief description of python scripts used for this analysis

- **`assemble_comparator.py`**: Assembles each project's final `results/comparator/comparator-{SEM}_PROJECT{NN}.md` from the human-issues list and the four sub-reports. Copies each sub-report verbatim. Run by the Comparator agent during step 3 of its workflow.  
- **`parse_comparator.py`**: Generates `comparator_results.csv` by regex-parsing the Counts tables and Coverage records directly out of the 72 assembled `comparator-*.md` files. `ms.qmd` and `ext.qmd` read this file for all figures and statistics. 
- **`comparator_results.csv`**: Output generated by the python script named above. One row per (semester, project, reviewer), 288 rows. Includes the A–F counts and the derived metrics (Human Overlap, AI-Unique Rate).
- **`extract_consensus_misses.py`**: Generates `consensus_misses.txt`, which assembles all human issues missed by all four reviewers, across all 72 projects. 
- **`extract_ac_findings.py`**: Generates `ac_findings.txt`, which contains every AI-unique (A/C) findings, for manual review or anecdote-hunting.
- **`categorized_misses.txt`**: Classifies aggregated list in `consensus_misses.txt` into the five themes listed in Figure 3 (`fig-themes`), done in a single pass by Claude. 
- **`count_themes.py`**: Generates `theme_counts.csv` by tallying `categorized_misses.txt`'s per-finding theme labels.
- **`theme_counts.csv`**: Output of the script above, backing `ms.qmd`'s Figure 3 (`fig-themes`).
- **`matrix_comparison.py`**: Generates **`matrix_comparison.png`**, which is `ms.qmd`'s Figure 4 (`fig-matrix`).  Per-agent "X.X/proj" counts (blocks 2–4) are computed directly from `comparator_results.csv`, not hardcoded.
