## Overall Assessment

This project investigates monthly malaria cases in Florida (2006–2016) using a SARIMA baseline and an adapted SEIR-with-splines POMP model, extended with an immigration term to reflect the imported nature of malaria cases in an endemic-free state. The epidemiological motivation for the immigration extension is sound and represents a genuine intellectual contribution. The authors correctly implement replicated pfilter with logmeanexp for likelihood evaluation, and the global search with 20 starting points reflects appropriate awareness of the multi-start requirement in iterated filtering. However, the project contains several technical issues that undermine its key conclusions: the central likelihood comparison between SARIMA and POMP is invalid because the two likelihoods are computed on different data scales; the measurement model has a significant coding inconsistency (sigma_M declared but unused, C tracked but I observed); and the global search has not converged, making parameter estimates and model comparisons unreliable. With targeted corrections — particularly fixing the measurement model, validating the initial population size, and adding a valid benchmark — the mechanistic modeling component could provide meaningful scientific insight.

## Key Strengths

**25.05.S1 — Correct likelihood evaluation machinery.** The authors correctly use replicated pfilter (10 replicates) followed by logmeanexp to evaluate the particle-filter log-likelihood. This is the technically appropriate approach and demonstrates understanding of Monte Carlo variability in likelihood estimation.

**25.05.S2 — Epidemiologically motivated immigration extension.** The addition of an immigration parameter to the I compartment is well-justified: malaria was eradicated locally in Florida, so observed cases represent imported infections. This is a scientifically interesting model extension that goes beyond mechanical adaptation of the source model.

**25.05.S3 — Reasonable global search design.** The global search uses 20 starting points with Np = 2000, Nmif = 100, and Np = 4000 for likelihood evaluation. This represents a reasonable computational effort for a course project and correctly distinguishes between local and global optimization.

## Major Points

**25.05.1 — Invalid likelihood comparison between SARIMA and POMP.** Severity: Major. The paper concludes there is "significant scope for improvement" in the POMP model based on the gap between the SARIMA log-likelihood (-96) and the POMP log-likelihood (~-330). However, the SARIMA model is fitted on log1p-transformed counts while the POMP model is fitted on raw count data. These likelihoods are not on the same scale and cannot be compared as evidence of relative model quality. Suggested action: Remove or clearly caveat the direct comparison. To enable a valid comparison, fit a non-mechanistic model (e.g., ARMA or negative binomial regression) on raw count data and compare its log-likelihood to the POMP model's log-likelihood on the same scale.

**25.05.2 — No valid benchmark on the same data scale.** Severity: Major. Because the SARIMA comparison is invalid, there is no non-mechanistic baseline against which the POMP model can be assessed. It is therefore impossible to determine whether the mechanistic SEIR structure provides any improvement over a standard time-series model. Suggested action: Fit at least one non-mechanistic model (Poisson ARMA, negative binomial regression with seasonal terms) to the raw count data and report its log-likelihood alongside the POMP model's value.

**25.05.3 — sigma_M declared but never used; measurement model is pure Poisson.** Severity: Major. The parameter sigma_M is listed in the parameter table as "Fixed measurement overdispersion" and included in paramnames and the log-transform list, but neither rmeas nor dmeas references it anywhere. The measurement model is a pure Poisson (`Y = rpois(rho * I + 1e-6)` and `lik = dpois(Y, rho * I + 1e-6, give_log)`). sigma_M is an orphaned parameter that does not contribute to the likelihood while the text implies overdispersion is modeled. Suggested action: Either remove sigma_M from all declarations and the parameter table, or implement a negative binomial measurement model using sigma_M as the dispersion parameter and update rmeas, dmeas, and the mathematical description accordingly.

**25.05.4 — Cumulative case tracking inconsistent with measurement model.** Severity: Major. The model accumulates `C += rho * dEI` (newly becoming infectious per time step) with accumvars = "C" (C reset to zero at each observation), but the measurement model observes `rho * I` (current count of infectious individuals). These measure different epidemiological quantities: C captures incident cases over the interval while I captures point-prevalence. The C state is never observed; the observation uses a disconnected quantity. Suggested action: If the intent is to observe new cases per month, use `Y ~ Poisson(rho * C)` where C is accumulated dEI per observation period. If the intent is to observe point-in-time prevalence, do not use accumvars, and explain why I is the appropriate observable. The mathematical description, code, and biological interpretation must be made consistent.

**25.05.5 — Convergence not demonstrated; cannot distinguish identifiability from computation.** Severity: Major. Trace plots in Figure 9 show most parameters (spline coefficients b_1–b_5, epsilon, gamma, mu_EI, rho) broadly spread at iteration 100 with no convergence to common values. The log-likelihood traces do not converge across chains. The paper attributes this to "weak identifiability" without ruling out that more iterations would improve convergence. Parameter estimates and model comparisons are unreliable until the log-likelihood has stabilized. Suggested action: Run the global search to at least 200–300 iterations and verify that the best log-likelihood does not improve from iteration 100 to 200 before concluding that parameter spread reflects identifiability rather than optimization failure.

**25.05.6 — No profile likelihoods or confidence intervals.** Severity: Major. All parameter estimates (rho = 0.27, immigration_rate = 1.82, etc.) are reported without any uncertainty quantification. The scatter in Figure 10 shows a flat likelihood surface with no visible peak structure for any parameter, suggesting parameters are poorly constrained. Without profile likelihoods or MCAP confidence intervals, no biological interpretation of parameters is defensible. Suggested action: Compute profile likelihoods for at least the epidemiologically interpretable parameters (rho, immigration_rate). If computational resources are limited, compute a likelihood slice and note its limitation, or report MCAP confidence intervals.

**25.05.7 — Biologically implausible parameter estimates not discussed.** Severity: Major. The global search best estimate gives mu_EI = 0.44 (mean latent period ~2.3 days) and gamma = 1.32 (mean infectious period ~0.76 days). For malaria, the intrinsic incubation period is approximately 10–14 days and the infectious period is several weeks. The optimized values are 10–20 times too large and biologically impossible. The paper does not comment on this discrepancy. Implausible estimates are a signal of model misspecification or optimization failure that must be addressed. Suggested action: Discuss the discrepancy explicitly. Consider fixing mu_EI and gamma at their biologically known values and optimizing only the remaining free parameters, or flag the implausibility as evidence that the current model structure does not adequately represent malaria dynamics in Florida.

**25.05.11 — N_0 = 100,000 far below Florida's actual population.** Severity: Major. The model initializes N_0 = 100,000 while Florida's population over 2006–2016 was approximately 18–20 million. All parameters that interact with N — the force of infection (lambda = beta * I/N), the reporting rate (rho), and immigration_rate — are systematically miscalibrated. With N underestimated by a factor of ~200, the implied prevalence fraction I/N and the effective transmission rate are inflated by the same factor, which likely contributes to the implausible gamma and mu_EI estimates obtained in optimization. Suggested action: Initialize N_0 at approximately Florida's actual population (~18–20 million), rescale E_0 and I_0 proportionally, and re-run optimization.

## Minor Points

**25.05.8 — Initial r = 0.135 is implausible as monthly birth rate.** Severity: Minor. The initial birth rate r = 0.135 per month implies 14.5% monthly population growth, which is biologically impossible for humans. This appears to be an uncorrected carryover from the dengue source model. The global search explores r ∈ [0, 0.001] which is more appropriate. The initial value should be corrected to approximately 0.001 per month (consistent with Florida's demographic rates).

**25.05.10 — Reported loglik = -332.02 inconsistent with printed output.** Severity: Minor. The text states both models "yield the same likelihood (-332.02)" but the printed best-chain replicated pfilter log-likelihoods are -331.39 and -331.08 respectively. The value -332.02 appears to come from an earlier (possibly single-run pfilter) computation and should be updated to the correct logmeanexp estimates.

**25.05.12 — ESS not monitored.** Severity: Minor. Effective sample size from pfilter runs is never reported or plotted. Given the Poisson measurement model applied to small monthly counts, filter degeneracy is plausible. ESS monitoring would confirm filter health and detect potential problems.

**25.05.13 — Forward simulations presented as fit assessment.** Severity: Minor. Figures 8 and 11 show unconditioned forward simulations (prior predictive checks using the best parameter set), not filtered trajectories conditioned on the data. The paper should clarify that these figures assess whether the model can generate plausible data, not whether it fits the actual observed series. Filtered trajectories or one-step-ahead prediction intervals would be more informative.

**25.05.M1 — Immigration model improvement is marginal by AIC.** Severity: Minor. The log-likelihood improvement from the base model (-331.39) to the immigration model (-329.76) is approximately 1.6 units for one additional parameter. An AIC penalty of 2 for the added parameter means DAIC ≈ +0.4 in favor of the simpler model. The claim that immigration "explains the model fit better" should be qualified as a marginal improvement that does not clearly justify the added complexity by standard information criteria.

**25.05.15 — Notation error in SARIMA equation.** Severity: Minor. The SARIMA model equation writes `(1+theta_1)` where it should be `(1+theta_1*B)` for the non-seasonal MA(1) polynomial. The backshift operator B is missing from the first factor.

**25.05.14 — Periodogram x-axis label incorrect.** Severity: Minor. The code sets `xlab = "Frequency (cycles per year)"` but spec.pgram with frequency = 12 produces frequencies in cycles per month. The dominant frequency of 0.0888 is in cycles per month (period = 12 months), so the axis label should read "Frequency (cycles per month)."
